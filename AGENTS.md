# ALP — análise das eleições de 2026

Projeto público de Fábio Souza / CrânIA. Neste checkout, herdar as instruções
de `../AGENTS.md` e os padrões CES indicados ali quando disponíveis. O projeto
deve funcionar para leitores externos sem CES, ALP, login ou banco privado.

- Publicar código próprio, método, fontes, hashes e pequenos resultados agregados.
- Nunca adicionar dados brutos, bancos, arquivos de terceiros, transcrição integral,
  mídias, perfis, conversas, logs privados, segredos ou caminhos da máquina ao Git.
- Alegação do vídeo não é resultado reproduzido. Registrar ambos separadamente.
- Não inferir fraude, óbito, identidade ou transferência individual de voto
  a partir de agregados. Conclusões exigem evidência apropriada ao enunciado.
- Não importar código de terceiros sem licença compatível e atribuição.
- Não alterar fontes locais nem ativar dados no Pergunte Aí como efeito da análise.
- Usar caminhos relativos e Python com biblioteca padrão sempre que possível.
